# Vendinha por Confiança · AA2

Base da aplicação em React, com Vite, React Router e o tema Tailwind da AA1.

## Executar localmente

Com Node.js 24 de referência, execute a partir da pasta `AA1-DSW2`:

```bash
cd aa2
npm ci
npm run dev
```

Abra o endereço exibido pelo Vite. Para gerar o build, execute `npm run build`.

| Rota | Tela |
| --- | --- |
| `/` | Início |
| `/produto/exemplo` | Produto com ID na URL |
| `/pagamento/exemplo` | Pagamento do produto |
| `/vendedor` | Painel do vendedor |

As telas iniciais servem para verificar a navegação. Os dados e formulários serão integrados nas próximas tarefas.
