# Vendinha por Confiança

Protótipo acadêmico desenvolvido para a AA1 da disciplina Desenvolvimento de Sistemas Web II.

A aplicação representa uma plataforma para vendinhas autônomas: o comprador consulta um produto, informa a quantidade retirada e visualiza os dados de pagamento Pix do vendedor. O vendedor possui telas para cadastro, produtos, estoque e relatórios.

## Tecnologias

- HTML5
- CSS com Tailwind CSS
- JavaScript
- Node.js para validações e testes locais

## Telas

- Página inicial da plataforma
- Página do produto
- Pagamento via Pix (simulado)
- Cadastro do vendedor
- Painel do vendedor
- Cadastro de produto
- Relatórios de vendas e estoque

## Como executar

Abra o arquivo `index.html` em um navegador ou utilize uma extensão de servidor local, como Live Server.

Para gerar o CSS e executar as verificações, é necessário ter Node.js instalado:

```bash
npm install
npm run build
npm run check
npm test
```
